# Splunk Certified Cybersecurity Defense Engineer

**Tipo:** ruta de especialización en ingeniería defensiva.

Este repositorio conserva el nombre **Splunk Certified Cybersecurity Defense Engineer** como término exacto de búsqueda y objetivo de aprendizaje, diferenciado de **Splunk Certified Cybersecurity Defense Analyst**.

## Estado de la documentación
Todavía no se incorpora una lista de cursos, módulos, requisitos ni laboratorios atribuidos a esta certificación porque no se dispone aquí de una verificación suficiente de esos elementos en el catálogo oficial.

## Criterio de ampliación
Añadir únicamente:
- Títulos oficiales de cursos confirmados.
- Competencias descritas por Splunk Training.
- Requisitos de certificación publicados oficialmente.
- Ejercicios y laboratorios realmente realizados.

No asumir que los cursos de la ruta Defense Analyst son automáticamente requisitos de Defense Engineer.
