# Splunk SOAR Certified Automation Developer (Legacy)

**Estado de la denominación:** Legacy, según la referencia de certificaciones consultada durante la búsqueda.

**Tipo:** especialización de automatización y orquestación de seguridad con Splunk SOAR.

## Cursos oficiales identificados
- Introduction to Splunk SOAR
- Implementing Splunk SOAR Community Playbooks
- Developing Splunk SOAR Apps

## Competencias
- Arquitectura y componentes de Splunk SOAR.
- Implementación y adaptación de playbooks comunitarios.
- Desarrollo de aplicaciones para Splunk SOAR.
- Integraciones y automatización de tareas de respuesta.

## Práctica
Documentar playbooks, integraciones y pruebas únicamente después de implementarlos en un entorno autorizado. No se registra actualmente un laboratorio SOAR como ejecutado.

## Nota
Esta ruta se mantiene separada de Splunk Certified Cybersecurity Defense Analyst y Splunk Certified Cybersecurity Defense Engineer. La designación Legacy se conserva para no presentar la certificación como una credencial vigente sin comprobar su estado actual.
