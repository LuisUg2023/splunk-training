# Laboratorios — Splunk Training

Los laboratorios se documentan a medida que se ejecutan. Cada informe debe incluir objetivo, curso relacionado, requisitos, procedimiento, consultas SPL, resultado esperado, resultado observado, capturas auténticas, análisis y conclusión.

| Código | Laboratorio | Etapa | Estado documental |
|---|---|---|---|
| LAB-01 | Interfaz, incorporación de datos y búsquedas iniciales | Fundamentos | Diseño inicial; no registrar como ejecutado |
| LAB-02 | Consultas SPL y análisis de registros | Búsqueda y análisis | Planificado |
| LAB-03 | Panel de monitoreo, informes y alertas | Visualización | Planificado |
| LAB-04 | Detección de actividad sospechosa | Detección | Planificado |
| LAB-05 | Investigación de incidente | Respuesta | Planificado |
| LAB-06 | Administración y monitoreo de Splunk | Administración | Planificado |

## Plantilla de informe
Copiar esta estructura al crear cada informe:

1. Objetivo.
2. Curso oficial relacionado.
3. Entorno y requisitos.
4. Dataset utilizado y procedencia.
5. Procedimiento paso a paso.
6. Consultas SPL explicadas.
7. Resultado esperado.
8. Resultado observado (solo después de ejecutar).
9. Evidencias y capturas sanitizadas.
10. Análisis técnico.
11. Conclusiones y mejoras.
