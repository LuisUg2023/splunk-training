# Laboratorios — Splunk Training

Los laboratorios se documentan a medida que se ejecutan. Cada informe debe incluir objetivo, ruta de aprendizaje relacionada, curso oficial, requisitos, procedimiento, consultas SPL, resultado esperado, resultado observado, capturas auténticas, análisis y conclusión.

| Código | Laboratorio | Ruta relacionada | Estado documental |
|---|---|---|---|
| LAB-01 | Interfaz, incorporación de datos y búsquedas iniciales | Splunk Core Certified User | Diseño inicial; no registrar como ejecutado |
| LAB-02 | Consultas SPL y análisis de registros | Splunk Core Certified Power User | Planificado |
| LAB-03 | Panel de monitoreo, informes y alertas | Splunk Core Certified Power User | Planificado |
| LAB-04 | Detección de actividad sospechosa | Splunk Certified Cybersecurity Defense Analyst | Planificado |
| LAB-05 | Investigación de incidente | Splunk Certified Cybersecurity Defense Analyst | Planificado |
| LAB-06 | Administración y monitoreo de Splunk | Splunk Enterprise Certified Admin | Planificado |

La ruta **Splunk Certified Cybersecurity Defense Engineer** y la especialización **Splunk SOAR Certified Automation Developer (Legacy)** se mantienen documentadas por separado. No se les asigna un laboratorio no verificado.

## Plantilla de informe

Copiar esta estructura al crear cada informe:

1. Objetivo.
2. Ruta de aprendizaje y curso oficial relacionado.
3. Entorno y requisitos.
4. Dataset utilizado y procedencia.
5. Procedimiento paso a paso.
6. Consultas SPL explicadas.
7. Resultado esperado.
8. Resultado observado (solo después de ejecutar).
9. Evidencias y capturas sanitizadas.
10. Análisis técnico.
11. Conclusiones y mejoras.
